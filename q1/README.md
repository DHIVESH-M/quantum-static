# Quilsbee Static Frontend

A clean, responsive static landing page for the Quilsbee quantum learning project.

## Included
- Light / dark mode toggle
- Interactive sample comic reader using Chapter 01 pages from the supplied Quantum Manga PDF
- Previous / Next navigation
- Keyboard arrow navigation
- Auto-play comic pages
- Fullscreen reader
- Project access cards for website, GitHub and demo folder
- Responsive mobile layout
- No build step required

## Run
Open `index.html` directly, or use any static server.

Example:
`python -m http.server 5500`

Then visit `http://localhost:5500`.
